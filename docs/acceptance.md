# MVP 工程验收

本记录区分功能验证和自主诱导，不能把程序化填写蜜罐当成框架受骗。

## 已验证

- 原始HTML注入：默认3个隐藏入口，保留业务内容，重复调用不会重复插入；非法origin/prefix被拒绝。
- JS/TS：纯函数、Node服务和浏览器入口，TypeScript严格模式检查通过。
- NPM tarball：独立临时目录离线安装，JS导入和CLI注入通过；不包含examples、tests、experiments、results和evidence。
- 状态机：模拟访问码、来源绑定、nonce和stage检查；并发确认只能完成一次，越阶段和重放被拒绝。
- IP封禁：首次有效模拟凭据提交后业务API和静态资源均403；伪造X-Forwarded-For无效，可信代理链解析单独覆盖；TTL后恢复。
- 目标先后顺序：封禁前取得目标仍保留攻击成功事件。
- SQLite：重开可读取，数量限制、过期清理及管理员清空可用。
- 静态/代理网关：HTML注入、管理接口认证、Cookie和JSON透传；服务端库嵌入示例通过。
- 浏览器：1366px和390px真实Chromium验收登录失败/成功、分页、搜索、空状态、详情、客户/资产导航、退出；无页面脚本错误，无整页横向溢出，表格可横向滚动。

## 尚不承诺

尚未验证所有前端框架、CDN封禁传播、长时高并发和正常用户误触发率。自动封禁默认不启用，需接入者选择block。浏览器补充注入不替代服务器或构建注入。SQLite Node API在本次24.14.0运行环境带实验性警告，应随部署版本验证。

自主CAI对照另见evidence中的冻结计划和摘要；失败的构建批次保留，不计防御成功。

独立Docker镜像在network=none、只读根目录、10001:10001、CPU/内存/PID上限与tmpfs数据目录下，静态HTML注入通过；验收后容器已删除。

[首轮CAI对照结果](mvp-abc-002.md)：三组均攻击成功，观察组有部分自报提交，未触发自主封禁。

分层版本增加：遍历有界归档树验证祖先关联、每层新增分支、内容可重复、叶节点终止与越界404；直接验证首阶段有效提交即封禁，错误访问码或空字段不触发。

高密度测试验证8个首页入口、每条记录继续展开8条新记录、四层关联及4096节点越界拒绝。
